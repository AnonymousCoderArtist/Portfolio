Hey there, fellow code explorer! 👋 Welcome to the repository for my personal portfolio website. I built this thing from the ground up – yup, from the initial **design concepts** in Figma (probably 😉) to **slinging code** and wrestling with **animations**. The goal? To create something visually engaging and maybe *just a little bit* over-the-top to showcase my skills (and have some fun along the way!). 🚀

 Dive in, explore the code, get inspired, or just see how I made that cool effect you liked! 😎

## 🔥 Features That Pack a Punch! 🔥

*   🎨 **100% Custom Built:** Designed, coded, and animated entirely from scratch. No templates here!
*   🎬 **Smooth GSAP Animations:** Leveraging the power of GreenSock (GSAP) and ScrollTrigger for silky-smooth, scroll-based animations.
*   🌀 **3D Elements:** Integrated 3D models and scenes using Spline & Three.js for that extra *wow* factor.
*   ↔️ **Interactive Carousels:** Using Swiper.js for slick testimonial and "About Me" sliders.
*   🖱️ **Engaging Hover Effects:** Subtle (and not-so-subtle) hover effects throughout the site, including text scrambles and reveals.
*   📜 **Lenis Smooth Scrolling:** For a fluid and premium browsing experience.
*   📱 **Fully Responsive:** Adapts beautifully to different screen sizes – works on desktop, tablet, and mobile! (Go ahead, resize that window!)
*   ⚙️ **Canvas Magic:** Custom canvas animations for the hero character and the social links background.
*   ⚡ **Performance:** Optimized with techniques like lazy loading for images and CSS/JS compression (`compressed.css`/`.js` spotted!).
*   🤖 **Bento Grid Projects:** A modern layout to showcase various projects, from AI Jarvis bots to FullStack clones!
*   ✨ **And much more!** Explore the sections: Home, About, Projects, Skills, Testimonials, Contact.

## 🛠️ Tech Stack Used 🛠️

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Animation:**
    *   GSAP (GreenSock Animation Platform)
    *   ScrollTrigger (GSAP Plugin)
*   **3D & Graphics:**
    *   Three.js
    *   Spline (@splinetool/viewer)
    *   HTML Canvas API
*   **Scrolling:** Lenis
*   **UI Components:** Swiper.js (for sliders)
*   **Interactivity:** Tilt.js (implied by `data-tilt` - *make sure you included it if using!*)
*   **Fonts:** Google Fonts (Electrolize)
*   **Possibly:** jQuery (included via CDN, might be used for specific plugins or helpers)

## 🚀 Getting Started & Running Locally 🚀

Want to run this project on your local machine? Easy peasy!

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git](https://github.com/AnonymousCoderArtist/Portfolio.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd Portfolio
    ```

3.  **Open `index.html` in your browser:**
    *   **Simple Way:** Just double-click the `index.html` file.
    *   **Recommended Way (VS Code):**
        *   Make sure you have the "Live Server" or "Live Preview" extension installed in Visual Studio Code.
        *   Right-click on `index.html` in the VS Code explorer.
        *   Select "Open with Live Server" or "Show Live Preview". ⚡ This helps with automatic reloading and handling some types of requests better than just opening the file directly.

And voilà! You should see the website running locally. 🎉

## 🧠 Code Philosophy & Highlights 🧠

*   **Show, Don't Just Tell:** The aim was to visually demonstrate capabilities through the website itself.
*   **Attention to Detail:** Focused on micro-interactions, smooth transitions, and a polished feel.
*   **Experimentation:** Played with various libraries (GSAP, Three.js, Spline) to create unique effects.
*   **Modularity (Attempted!):** While it's a single-page application, the structure tries to keep sections distinct (HTML sections, potentially different JS modules if `compressed.js` combines them).
